대체 과제

특강에 참여하지 못하셨다면, 강의 내용을 따라 직접 사이트를 만들고 배포해서 올려주세요.

Submit

제출 조건

  • 강의에서처럼 내 소개 페이지를 만듭니다. 다른 주제여도 괜찮습니다
  • GitHub에 퍼블릭 레포로 올립니다
  • Vercel로 배포해서 로그인 없이 누구나 열리는 주소를 만듭니다
  • 그 주소를 결과물 공유 페이지에 올립니다
공유 페이지에 올리면 제출 완료입니다.
How

수행 방법

1준비하기

개인 노트북, Claude Pro 요금제 이상, GitHub 계정이 필요합니다. 터미널에 아래 세 줄을 입력해보세요.

claude --version git --version gh --version

세 줄 모두 버전 숫자가 뜨면 준비 완료입니다.

2강의 따라 만들기

슬라이드를 보면서, 프롬프트 모음의 순서대로 복사해서 붙여넣으시면 됩니다.

Part 2
폴더 만들고 claude 실행
3-1
CLAUDE.md 세팅
3-2
/plan 으로 계획 받고, 읽고 고치기
3-3 · 3-4
구현하고 localhost:3000 에서 확인
3-5
GitHub 퍼블릭 레포에 올리기
슬라이드 보기 프롬프트 모음
에러가 나면 화면을 캡처해서 Ctrl + V 로 붙여넣고 “이 에러 고쳐줘” 라고만 보내세요.

3Vercel로 배포하기

  1. vercel.com 접속 → GitHub로 로그인
  2. Add New → Project → 방금 만든 레포 Import
  3. Deploy 누르고 2~3분 기다리기
  4. 프로젝트 화면의 Domains 에 보이는 주소 복사

4누구나 열리는지 확인하기

로그인 화면이 뜨는 주소는 확인할 수 없습니다. 제출 전에 꼭 확인해주세요.

올릴 주소
my-project.vercel.app 처럼 짧은 주소
안 되는 주소
my-project-a1b2c3-...-projects.vercel.app 처럼 긴 주소. 본인 말고는 Vercel 로그인 화면이 뜹니다
  1. 휴대폰이나 브라우저 시크릿 창에서 주소를 엽니다
  2. 로그인 없이 내 페이지가 바로 뜨면 통과입니다
짧은 주소에서도 로그인 화면이 뜬다면 Vercel 프로젝트의 Settings → Deployment Protection 에서 Vercel Authentication 을 끄고 다시 확인하세요.

5공유 페이지에 올리기

  1. 이름 칸에 실명
  2. 링크 칸에 4번에서 확인한 짧은 주소
  3. 한 줄 설명 맨 앞에 [대체과제] 를 붙여주세요

예) [대체과제] 관심사와 링크를 담은 소개 페이지
