Part 4

복사·붙여넣기 없애기

Claude는 기본적으로 내 폴더와 터미널만 다룹니다. 노션, 슬랙, 구글시트는 모릅니다.

MCP는 그 사이를 이어주는 표준 규격입니다.

노션 연결하기

1. Claude Code 밖 터미널에서 claude mcp add --transport http notion https://mcp.notion.com/mcp 2. claude 다시 실행 후 /mcp → notion 선택 → 인증
내 Notion 페이지 다시 읽어서 사이트 내용 업데이트하고, 커밋·푸시해줘
노션에서 한 줄 고치면 실제 사이트가 바뀝니다. 아까 손으로 복붙했던 게 이제는 자동으로 돕니다.

반복되는 일 저장해두기

같은 설명을 세 번째 하고 있다면, 파일로 저장해두라는 신호입니다.

Skills — 자주 쓰는 작업 방식을 파일 하나로 저장하고 /이름 으로 꺼내 쓰는 기능.

내 프로젝트 심사 스킬

1. 이 서비스가 없으면 사용자는 지금 뭐로 해결하고 있나? 그것보다 나은가? 2. 화면에 있는 기능 중, 없어도 되는 건 뭔가? 3. 이 기술을 왜 썼나? 더 단순한 방법은 없었나?
오늘만 쓰고 말 게 아닙니다. 다음주 해커톤에서도 그대로 씁니다.

이런 것도 있습니다

Hooks

특정 상황에서 자동 실행. 위험한 명령을 코드로 확실하게 막습니다.

Sub-agents

Claude가 다른 Claude에게 일을 나눠줍니다. 메인 대화가 안 지저분해집니다.

오늘 안 만들어도 됩니다. Sub-agents는 에이전트 수만큼 사용량을 씁니다. 처음엔 하나로 충분합니다.

플러그인

스킬, 자동화, 외부 연결을 한 세트로 묶은 꾸러미. 앱 설치와 같습니다.

/plugin 둘러보기 /plugin install [이름] 설치 → 껐다 켜야 적용됩니다
처음부터 많이 깔지 마세요. 불편한 게 생겼을 때 하나씩 추가하는 순서가 맞습니다.
